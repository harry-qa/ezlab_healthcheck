# Playwright 기반 이지랩(ezLab) 서비스 헬스 체크 자동화

본 프로젝트는 [이지랩(ezLab)](https://ezlab.im) 서비스의 배포 후 안정성을 신속하게 검증하기 위해 구축된 하이브리드 자동화 도구입니다.

## 1. 개요

이지랩 전체 서비스(이지캡쳐, 이지집, 이지파인더, 이지메모, 이지캠, 이지리더)를 대상으로 서버 생존, API 응답, UI 링크 연결, 다운로드 페이지, 콘텐츠 무결성, 이미지 로딩, 로그인 폼을 다국어(ko/en/jp/tw) 환경에서 통합 점검합니다. 기존의 수동 점검 방식에서 벗어나 QA 공수를 절감하고 배포 품질을 확보하는 것을 목적으로 합니다.

## 2. 점검 항목 (7단계)

### STEP 1 · 다국어 서버 생존 확인
- `ezlab.im/ko`, `/en`, `/jp`, `/tw` 각 언어별 메인 페이지의 HTTP 상태 코드를 확인하여 서버 생존 여부를 즉각 판별합니다.

### STEP 2 · API 자동 수집 및 검증
- 각 언어 페이지를 탐색하면서 네트워크 인터셉트(XHR/Fetch)를 통해 내부 API 호출을 자동 수집하고, 상태 코드(4xx/5xx)를 검증합니다.

### STEP 3 · UI 링크 전수조사
- 홈페이지에서 수집한 내부 링크를 **depth 2**까지 재귀 탐색하여 누락 페이지 없이 전수 조사합니다.
- `<a>` 태그뿐 아니라 **탭 버튼 클릭으로 전환되는 페이지**(예: 이용약관 탭 구조)도 자동 감지합니다.
- `mailto:`, `.exe/.apk/.zip` 등 다운로드 파일 링크는 크롤링에서 제외합니다.
- 응답 3초 초과 시 SLOW로 분류하며, 콘텐츠 내 에러 키워드("점검중", "404 not found" 등)도 감지합니다.

### STEP 4 · 서비스별 다운로드 페이지 직접 검증
- 각 서비스(이지캡쳐~이지리더)의 개별 다운로드 페이지에 직접 진입하여 페이지 응답 상태와 다운로드 버튼(.exe/.apk/.zip) 존재 여부를 확인합니다.

### STEP 5 · 언어별 핵심 콘텐츠 무결성 확인
- 언어별 메인 페이지에서 핵심 키워드(ko: "다운로드", "이지캡쳐" 등 / en: "download", "ezcapture" 등 / jp: "ダウンロード" 등 / tw: "下載" 등)의 존재 여부를 검증하여 콘텐츠 누락을 감지합니다.

### STEP 6 · 깨진 이미지 감지
- 언어별 페이지의 모든 `<img>` 태그를 순회하여 이미지 로드 실패(4xx/5xx)를 감지합니다.
- CDN 장애 또는 경로 오류로 인한 이미지 깨짐을 자동으로 탐지합니다.

### STEP 7 · 로그인 폼 렌더링 확인
- 로그인 페이지 진입 후 카카오 / 네이버 / 구글 소셜 로그인 버튼의 렌더링 여부를 확인합니다.
- 인증 연동 장애를 조기에 감지합니다.

## 3. 주요 특징

- **다국어 통합 점검**: 한국어, 영어, 일본어, 중국어(번체) 4개 언어를 단일 테스트에서 순회
- **하이브리드 검증**: 서버 응답 + API 인터셉트 + UI 링크 크롤링 + 콘텐츠 검증 + 이미지/로그인 점검을 한 번에 수행
- **WAF 회피**: 일반 브라우저와 동일한 `User-Agent` 헤더 적용 및 랜덤 딜레이(300ms~800ms) 로직 구현
- **자동 리포팅**: 테스트 결과를 PASS/FAIL/WARN 카운터로 집계하고 장애 리포트(개발팀 전달용) 자동 생성
- **실패 알림**: 헬스체크 FAIL 감지 시 GitHub Issue 자동 생성
- **네트워크 오류 대응**: CI 환경에서 일시적 오류에 대해 1회 자동 재시도

## 4. 리포트 인덱스

GitHub Pages 인덱스 페이지에서 누적 실행 이력을 한눈에 확인할 수 있습니다.

- **PASS / FAIL / WARN 상태 배지**: 각 실행별 결과를 목록에서 바로 확인
- **전체 요약 카운트**: 누적 PASS/FAIL/WARN 집계
- **서버 응답 시간 트렌드**: 최근 12회 ko/en/jp/tw 서버 응답 시간을 색상 바 차트로 시각화 (초록: 1초 미만 / 노랑: 1~3초 / 빨강: 3초 초과)

## 6. 기술 스택

- **Language**: TypeScript
- **Framework**: Playwright
- **Runtime**: Node.js
- **CI/CD**: GitHub Actions
- **Report Hosting**: GitHub Pages

## 7. 실행 방법

```bash
# 의존성 설치
npm install

# Playwright 브라우저 설치
npx playwright install

# 테스트 실행
npx playwright test

# HTML 리포트 확인
npx playwright show-report
```
